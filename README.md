# Shabnam Elegant — İş elbisesi katalog sitesi ve yönetim paneli

- Site: Rusça / Özbekçe (Latin) · Yönetim paneli: Türkçe / Rusça (`/admin`)
- Teknoloji: React + FastAPI + MongoDB, Docker Compose ile tek komutta kurulum

## Yayına alma (Hostinger VPS)
Adım adım rehber: **[deploy/KURULUM.md](deploy/KURULUM.md)**

Kısaca: Hostinger → VPS → Docker Manager → Compose from URL → bu deponun adresi →
`deploy/env.example` içindeki değişkenleri Environment bölümüne girin → Deploy.
